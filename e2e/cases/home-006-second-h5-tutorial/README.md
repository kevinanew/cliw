# HOME-006：首页第二组 H5 教程入口与返回

## 目的

验证首页第二组“添加至手机桌面”入口确实打开对应教程，并检查教程中两处 H5 地址一致。

## 前置条件

- 优先级：P1
- 入口：`/?lang=zh`
- 视口：桌面、手机
- 语言：简体中文
- 账号与数据：公开页面，无账号；第二组对应 `laiwanpai-com`

## 步骤与预期

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 打开中文首页 | 首页标题可见 |
| 2 | 点击第二组教程入口 | 进入 `/h5-tutorial/laiwanpai-com?lang=zh`，保留语言 |
| 3 | 检查教程介绍和第一步中的链接 | 两处 H5 地址均使用 HTTPS，显示文字与目标地址一致 |
| 4 | 浏览器返回 | 回到中文首页，第二组入口可见 |

此案例验证网站内的教程流程；系统浏览器“添加到主屏幕”操作需真实设备验证。
