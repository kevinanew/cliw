# LEARNING-001：学习资料下载入口

## 目的

验证公开页面的学习资料下载入口。

## 前置条件

- 优先级：P2
- 入口：`/learning?lang=en`
- 视口：桌面、手机
- 语言：英文
- 账号与数据：公开页面，无账号；使用案例中写明的固定术语或资源。

## 步骤与预期

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 打开入口并检查页面已呈现 | 页面业务容器或目标控件唯一存在 |
| 2 | 检查下载链接和 PDF 响应 | 链接指向英文 PDF；资源返回 200 和 application/pdf |
