# LEARNING-002：中文书籍实际下载

## 目的

验证四本中文书均能通过页面按钮下载，文件名和资源对应正确，实际收到的文件具有 PDF 签名与结束标记。

## 前置条件

- 优先级：P1
- 入口：`/learning?lang=zh`
- 视口：桌面、手机
- 语言：简体中文
- 账号与数据：公开书籍，无账号；每本书使用独立测试和浏览器上下文
- 文件：无限德州扑克进阶指南、德州扑克战术与策略分析、德州扑克小绿皮书、德扑蓝皮书；确切路径及下载文件名在 spec 的 books 表中维护

## 步骤与预期

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 按稳定业务 ID 定位书籍卡片 | 卡片唯一、书名正确，卡片内下载按钮唯一，href 和 download 文件名匹配 |
| 2 | 真实点击下载按钮 | 产生浏览器 download 事件，文件名和下载路径正确，下载完成且无失败 |
| 3 | 读取实际下载文件 | 文件大小大于 1 KB；开头为 `%PDF-`，尾部包含 `%%EOF` |

不使用另外发起的固定地址请求代替点击下载。文件由浏览器上下文临时保存，关闭后清理，不加入 Git 或 CI 报告。首尾标记用于发现 HTML 错页、空文件和常见截断，不代表校验整本文档内容。
