# HOME-004：Apple 下载弹窗与商店入口

## 目的

验证 Apple 下载弹窗可打开、关闭和再次打开，点击商店入口会发出对应应用的主页面导航请求。

## 前置条件

- 优先级：P1
- 入口：`/?lang=zh`
- 视口：桌面、手机
- 语言：简体中文
- 账号与数据：公开页面，无账号；商店应用 ID 为 `1394482339`

## 步骤与预期

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 打开首页，点击 Apple 下载入口 | 唯一弹窗可见，提供地区限制说明和商店入口 |
| 2 | 点击关闭，再打开并按 Escape | 两种方式均关闭弹窗，入口仍可用 |
| 3 | 再次打开并点击商店入口 | 链接使用 HTTPS、指向 apps.apple.com 的应用 1394482339；点击后发出该地址的主页面导航请求 |

商店可能按地区和语言重定向，因此不固定地区目录和应用名称。测试只拦截商店地址的响应并返回测试接收页，保留站点真实点击和导航行为，避免手机端唤起原生应用导致 CI 导航中断。此案例不验证第三方商店可用性、系统安装、账号登录或应用启动。
