# HOME-005：从 Apple 弹窗进入下载教程并返回

## 目的

验证首页弹窗的站内下载教程入口、教程内容与浏览器返回流程。

## 前置条件

- 优先级：P1
- 入口：`/?lang=zh`
- 视口：桌面、手机
- 语言：简体中文
- 账号与数据：公开页面，无账号

## 步骤与预期

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 打开 Apple 下载弹窗 | 弹窗可见 |
| 2 | 点击“中国大陆如何下载” | 进入 `/tutorial?lang=zh`；第一步可见并介绍 AppleID |
| 3 | 浏览器返回并再次打开弹窗 | 回到中文首页，下载入口仍可用 |

## 定位契约

| 业务目标 | data-testid | 状态 |
| --- | --- | --- |
| 下载入口与弹窗 | `ios-download-trigger`、`ios-download-modal` | 已确认 |
| 弹窗内指向 `/tutorial` 的链接 | `ios-download-modal-tutorial-link` | **建议标识，当前缺失，需业务源码补齐** |
| 教程第一步 | `tutorial-step-one` | 已确认 |
